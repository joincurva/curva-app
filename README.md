# Curva iPhone app

The Curva app for iPhone, built with Expo. Curva is a free, fan-first companion for live events: every official presale and on-sale in one calendar, reminders before the queue opens, and official tickets at face value.

This repository holds only the app. It talks to the public joincurva.com API. The website and server code are private.

Curva isn't affiliated with any artist, team, venue or ticketing company.
